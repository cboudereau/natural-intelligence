List every skill shipped by the ni plugin (natural intelligence) with a one-line summary of when it applies. Read each `SKILL.md` under `${CLAUDE_PLUGIN_ROOT}/skills/` and use its frontmatter `description`. Present the result as a table with columns Skill, Use when. Invoke skills as `ni:<skill>`, for example `ni:tdd`.
When the session had a wrong fix, a missed convention, or a slow search, point to `ni:retro`: it turns that friction into a check, a convention, or a pointer.
